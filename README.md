## Archive d'un projet d'étude en golang (première année).

#### But principal : pouvoir réaliser des animations 2D grâce à un seul pixel 1x1, qu'on dupliquera, fera changer de couleur, le faire rebondir, appliquer une gravité...

###### Note importante : pour faciliter le début car nous étions en première année, le code n'était pas vide. Quand on le lançait, seul un simple pixel blanc au milieu de l'écran était visible. Rien de plus.

###### Aussi, nous étions dirigés comme un TD pour  valider les besoins voulu par le professeur. La difficulté était croissante où 20/20 était le TD terminé.
